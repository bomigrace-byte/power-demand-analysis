# 대한민국 전체 전력수요량 시계열 분석

## 1. 프로젝트 개요

이 프로젝트는 AI Native Master 과정의 Mission 7인 **AI 데이터 분석: 데이터 기반 트렌드 분석** 미션을 수행하기 위해 만든 시계열 데이터 분석 프로젝트입니다.

분석 대상은 한국전력거래소에서 제공하는 **시간별 전국 전력수요량 데이터**입니다.  
2015년 1월 1일부터 2025년 12월 31일까지의 시간별 전력수요량을 일별·월별·연별 단위로 집계하고, 장기 추세, 계절성, 급격한 변화, 코로나 전·영향 기간·이후 구간 차이를 분석했습니다.

이 프로젝트는 단순히 그래프를 만드는 것이 아니라, 데이터를 바탕으로 다음 과정을 직접 수행하는 것을 목표로 합니다.

- 분석하고 싶은 문제 정의하기
- 데이터 구조 이해하기
- 분석 질문 만들기
- 결측치와 중복 확인하기
- 시계열 데이터를 일별·월별·연별로 집계하기
- 그래프와 통계량을 통해 패턴 확인하기
- 관찰 가능한 사실과 해석 가설을 구분하기
- 분석 결과의 한계점을 설명하기
- AI를 활용하되 결과를 직접 검증하기
- 분석 결과를 대시보드로 탐색 가능하게 만들기

## 2. 미션 의도

이 미션의 핵심은 단순히 그래프를 그리는 것이 아니라, 그래프와 수치에서 확인되는 패턴을 바탕으로 **“그래서 이게 무슨 의미인가?”** 를 해석하는 것입니다.

시계열 데이터는 시간의 흐름에 따라 값이 변합니다. 하지만 데이터는 스스로 의미를 설명하지 않습니다. 따라서 분석자는 직접 질문을 만들고, 데이터를 정제하고, 시각화하고, 패턴을 발견한 뒤, 관찰 가능한 사실과 가능한 해석을 구분해야 합니다.

이 프로젝트에서는 전국 전력수요량 데이터를 사용해 다음 내용을 확인했습니다.

1. 장기적으로 전력수요량이 증가했는가?
2. 월별·계절별 반복 패턴이 있는가?
3. 전일 대비 급격하게 증가하거나 감소한 날짜는 언제인가?
4. 코로나 이전·영향 기간·이후 구간의 전력수요량은 어떻게 다른가?

분석 과정에서는 그래프를 나열하는 데 그치지 않고, 각 결과가 어떤 의미를 가지는지와 어떤 한계가 있는지를 함께 정리했습니다.

## 3. 이 프로젝트를 만든 목적

전력수요량은 시간에 따라 변하는 대표적인 시계열 데이터입니다.

전력수요는 연도별로 보면 장기적인 증가 또는 감소 흐름을 확인할 수 있고, 월별·계절별로 보면 반복되는 패턴을 확인할 수 있습니다. 또한 일별 변화율을 계산하면 평소보다 전력수요가 크게 증가하거나 감소한 날짜도 찾을 수 있습니다.

이 프로젝트의 목적은 다음과 같습니다.

1. 2015~2025년 동안 전국 전력수요량이 어떻게 변화했는지 확인한다.
2. 월별·계절별 반복 패턴이 존재하는지 확인한다.
3. 전일 대비 변화율이 큰 날짜를 찾아 급격한 변화 후보를 확인한다.
4. 코로나 이전·영향 기간·이후 구간의 전력수요량 차이를 비교한다.
5. 시계열 분해와 간단한 baseline 예측을 통해 시계열 분석의 기초 개념을 학습한다.
6. Streamlit 대시보드를 만들어 사용자가 기간과 조건을 바꾸며 분석 결과를 탐색할 수 있게 한다.

이 분석은 전력수요 변화의 최종 원인을 확정하기 위한 것이 아닙니다. 현재 데이터에서 확인할 수 있는 패턴을 정리하고, 추가 데이터가 있다면 어떤 가설을 더 검토할 수 있는지 살펴보는 데 목적이 있습니다.

## 5. 분석 질문

최종 분석 질문은 다음 4개입니다.

### 질문 1. 장기 추세

2015~2025년 동안 우리나라 전체 전력수요량의 장기적인 추세는 어떻게 변화했는가?

이 질문은 연도별 총수요량과 전년 대비 변화율을 통해 확인합니다.

### 질문 2. 계절성

우리나라 전력수요량에는 반복되는 계절적 패턴이 나타나는가?

이 질문은 월별 평균 일일수요량과 계절별 평균 일일수요량을 통해 확인합니다.

### 질문 3. 급격한 변화

전력수요량이 평소보다 급격하게 증가하거나 감소한 시점은 언제인가?

이 질문은 전일 대비 변화율을 계산하고, 상위 1%와 하위 1% 기준을 사용해 급격한 변화 후보를 확인합니다.

### 질문 4. 코로나 구간 비교

코로나 이전·영향 기간·이후의 전력수요량은 어떻게 달라졌는가?

이 질문은 다음 세 구간의 평균 일일수요량과 변동성을 비교해 확인합니다.

- 코로나 이전: 2015-01-01 ~ 2019-12-31
- 코로나 영향 기간: 2020-01-01 ~ 2021-12-31
- 코로나 이후: 2022-01-01 ~ 2025-12-31

## 6. 데이터 설명

### 6.1 사용 데이터

- 제공 기관: 한국전력거래소
- 데이터 이름: 시간별 전국 전력수요량
- 분석 기간: 2015-01-01 ~ 2025-12-31
- 원본 단위: MWh
- 분석 단위: GWh
- 최종 일별 데이터 수: 4,018일
- 최종 월별 데이터 수: 132개월
- 최종 연별 데이터 수: 11년

원본 데이터는 날짜별로 1시부터 24시까지의 시간별 전력수요량을 포함하고 있습니다. 이 프로젝트에서는 시간별 값을 하루 단위로 합산해 일별 총수요량을 만들고, 이를 다시 월별·연별로 집계했습니다.

### 6.2 데이터 출처 및 사용 주의

이 프로젝트의 원본 데이터는 한국전력거래소에서 제공하는 시간별 전국 전력수요량 데이터를 사용했습니다.

원본 데이터는 연도별 CSV 파일 형태로 수집했으며, 프로젝트에서는 원본 파일을 전처리하여 `data/processed/` 폴더의 일별·월별·연별 CSV로 변환했습니다.

데이터 사용 시에는 한국전력거래소의 데이터 제공 조건과 이용 약관을 확인해야 합니다. 이 프로젝트는 교육 목적의 분석 과제로 작성되었으며, 원본 데이터의 상업적 사용 가능 여부나 재배포 가능 여부는 별도로 확인해야 합니다.

원본 데이터 파일을 GitHub에 포함하지 않는 경우, README.md와 REPORT.md에 데이터 출처와 수집 방법을 명시하여 재현 가능성을 보완합니다.

### 6.3 사용한 전처리 데이터

분석에는 다음 전처리 결과 파일을 사용합니다.

```text
data/processed/daily_demand.csv
data/processed/monthly_demand.csv
data/processed/yearly_demand.csv
```

각 파일의 의미는 다음과 같습니다.

| 파일 | 설명 |
|---|---|
| `daily_demand.csv` | 날짜별 총 전력수요량 데이터 |
| `monthly_demand.csv` | 월별 총 전력수요량과 월별 포함 일수 데이터 |
| `yearly_demand.csv` | 연도별 총 전력수요량과 연도별 포함 일수 데이터 |

### 6.4 데이터 포함 범위

최종 분석 데이터는 다음 범위를 포함합니다.

```text
2015-01-01 ~ 2025-12-31
```

최종 일별 데이터는 4,018일이며, 날짜가 끊기지 않고 연속적으로 존재하는지 확인했습니다.

## 7. 초보자를 위한 주요 개념 설명

### 7.1 시계열 데이터

시계열 데이터란 시간 순서가 중요한 데이터입니다.

예를 들어 다음과 같은 데이터가 시계열 데이터입니다.

- 날짜별 전력수요량
- 월별 매출
- 시간별 기온
- 일별 주가
- 주간 방문자 수

이 프로젝트에서는 `날짜`와 `전력수요량`이 함께 있으므로 시계열 데이터입니다.

### 7.2 집계

집계란 더 작은 단위의 데이터를 더 큰 단위로 묶어 계산하는 것입니다.

이 프로젝트에서는 시간별 데이터를 다음처럼 집계했습니다.

```text
시간별 전력수요량
→ 일별 총수요량
→ 월별 총수요량
→ 연별 총수요량
```

예를 들어 하루에는 1시부터 24시까지 24개의 값이 있습니다. 이 24개의 값을 모두 더하면 하루 전체 전력수요량이 됩니다.

### 7.3 단위 변환

원본 데이터의 단위는 MWh입니다. 보고서에서는 값을 더 보기 쉽게 만들기 위해 GWh로 변환했습니다.

```text
1 GWh = 1,000 MWh
```

따라서 일별 총수요량을 계산한 뒤 1,000으로 나누어 GWh 단위로 바꾸었습니다.

### 7.4 장기 추세

장기 추세는 시간이 지남에 따라 데이터가 전체적으로 증가하는지, 감소하는지, 정체되는지를 보는 것입니다.

이 프로젝트에서는 연간 총수요량을 사용해 장기 추세를 확인했습니다.

확인한 내용은 다음과 같습니다.

- 2015년 대비 2025년 전력수요량이 얼마나 증가했는가?
- 매년 계속 증가했는가?
- 중간에 감소한 해가 있었는가?
- 가장 높은 연도는 언제였는가?

### 7.5 계절성

계절성은 일정한 주기로 반복되는 패턴입니다.

예를 들어 매년 여름과 겨울에 전력수요가 높고, 봄과 가을에 낮다면 계절성이 있다고 볼 수 있습니다.

이 프로젝트에서는 다음 방식으로 계절성을 확인했습니다.

- 1월부터 12월까지 월별 평균 일일수요량 비교
- 봄, 여름, 가을, 겨울의 평균 일일수요량 비교
- 시계열 분해를 통한 계절성 성분 확인

### 7.6 변화율

변화율은 이전 값과 비교해 얼마나 증가하거나 감소했는지를 비율로 나타낸 값입니다.

이 프로젝트에서는 전날과 비교한 전일 대비 변화율을 사용했습니다.

예를 들어 어제 전력수요량이 1,000 GWh이고 오늘 전력수요량이 1,100 GWh라면 10% 증가입니다.

변화율을 사용하면 단순히 값이 큰 날이 아니라, **평소보다 갑자기 달라진 날**을 찾을 수 있습니다.

### 7.7 분위수

분위수는 데이터를 크기순으로 정렬했을 때 특정 위치에 해당하는 값입니다.

이 프로젝트에서는 변화율의 상위 1%와 하위 1%를 사용했습니다.

- 상위 1%: 전일 대비 증가율이 특히 컸던 날짜 후보
- 하위 1%: 전일 대비 감소율이 특히 컸던 날짜 후보

이 방법은 임의로 “10% 이상이면 급격한 변화”라고 정하는 대신, 전체 데이터 분포를 기준으로 후보를 찾는 방식입니다.

### 7.8 Fact와 Hypothesis

이 프로젝트에서는 관찰 가능한 사실과 해석 가설을 구분했습니다.

Fact는 데이터와 계산 결과에서 직접 확인할 수 있는 내용입니다.

예:

```text
2022년 연간 총수요량은 574,426.06 GWh로 분석 기간 중 가장 높았다.
```

Hypothesis는 데이터를 바탕으로 생각해볼 수 있는 해석입니다. 하지만 추가 데이터가 없으면 확정할 수 없습니다.

예:

```text
겨울과 여름의 높은 전력수요는 냉난방 수요와 관련되었을 가능성이 있다.
```

이 프로젝트에서는 기온, 공휴일, 산업활동 데이터가 없기 때문에 원인을 단정하지 않았습니다.

### 7.9 시계열 분해

시계열 분해는 하나의 시계열 데이터를 여러 성분으로 나누어 보는 방법입니다.

일반적으로 다음 요소로 나눕니다.

| 요소 | 의미 |
|---|---|
| Observed | 실제 관측값 |
| Trend | 장기적인 흐름 |
| Seasonal | 반복되는 계절 패턴 |
| Residual | 추세와 계절성으로 설명되지 않는 나머지 |

이 프로젝트에서는 월별 평균 일일수요량을 사용해 additive seasonal decomposition을 수행했습니다.

### 7.10 Baseline 예측

Baseline 예측은 복잡한 모델을 만들기 전에 사용하는 단순한 기준선입니다.

이 프로젝트에서는 마지막 30일을 대상으로 두 가지 기준선을 비교했습니다.

| Baseline | 의미 |
|---|---|
| 최근 30일 평균 | 테스트 직전 30일 평균값을 예측값으로 사용 |
| 전년 같은 날짜 | 작년 같은 날짜의 값을 예측값으로 사용 |

이 예측은 실제 미래 예측 모델을 만들기 위한 것이 아니라, 전력수요에 반복 패턴이 있는지 간단히 확인하기 위한 학습용 분석입니다.

## 12. 분석 코드 실행 방법



7. 날짜 연속성, 중복, 결측, 집계 일치 여부를 검증합니다.

## 15. 대시보드에서 직접 확인할 수 있는 것

### 15.1 기간 변경

사이드바에서 분석 기간을 선택할 수 있습니다.

예를 들어 2015~2025 전체 기간을 볼 수도 있고, 특정 기간만 선택해 일별 흐름을 볼 수도 있습니다.

### 15.2 일별 전력수요량 확인

일별 추세 탐색 화면에서는 선택한 기간의 전력수요량 흐름을 볼 수 있습니다.

이를 통해 다음을 확인할 수 있습니다.

- 특정 기간에 전력수요량이 높았는지
- 반복적으로 오르내리는 패턴이 있는지
- 최댓값과 최솟값이 어느 정도인지

### 15.3 월별·계절별 패턴 확인

월별·계절성 분석 화면에서는 다음을 확인할 수 있습니다.

- 1월부터 12월 중 어느 달의 전력수요량이 높은지
- 봄, 여름, 가을, 겨울 중 어느 계절이 높은지
- 전력수요량이 겨울·여름에 높고 봄·가을에 낮은지

### 15.4 급격한 변화 후보 확인

급격한 변화 후보 화면에서는 전일 대비 변화율이 큰 날짜를 확인할 수 있습니다.

이 화면에서는 다음 조건을 바꿔볼 수 있습니다.

- 증가 상위 날짜
- 감소 하위 날짜
- 상위·하위 1% 후보 전체
- 표시할 날짜 개수

이 결과는 이상치 확정이 아니라 **추가 검토가 필요한 변화 후보**입니다.

### 15.5 코로나 구간 비교

코로나 구간 비교 화면에서는 세 구간의 평균 일일수요량과 변동성을 비교합니다.

구간은 다음과 같습니다.

```text
코로나 이전: 2015-01-01 ~ 2019-12-31
코로나 영향 기간: 2020-01-01 ~ 2021-12-31
코로나 이후: 2022-01-01 ~ 2025-12-31
```

주의할 점은 이 분석이 인과관계를 증명하지 않는다는 것입니다. 즉, 구간별 차이는 확인할 수 있지만, 그 차이가 코로나 때문에 발생했다고 단정할 수는 없습니다.

## 16. 분석 결과 해석 방법

이 프로젝트의 결과를 볼 때는 다음 순서로 해석하는 것이 좋습니다.

### 16.1 먼저 질문을 확인한다

보고서와 대시보드는 질문 1~4를 기준으로 구성되어 있습니다.

```text
질문 1. 장기 추세
질문 2. 계절성
질문 3. 급격한 변화
질문 4. 코로나 구간 비교
```

그래프를 보기 전에 어떤 질문에 답하려는 분석인지 먼저 확인해야 합니다.

### 16.2 그래프에서 관찰 가능한 사실을 찾는다

예를 들어 장기 추세 그래프를 볼 때는 다음을 확인합니다.

- 어떤 연도가 가장 높은가?
- 어떤 연도에서 감소했는가?
- 전체적으로 증가했는가, 감소했는가?
- 특정 구간에서 정체되었는가?

이 단계에서는 원인을 단정하지 않습니다.

### 16.3 표에서 수치 근거를 확인한다

그래프만 보고 판단하면 정확하지 않을 수 있습니다. 따라서 `results/tables/` 폴더의 CSV 결과나 `REPORT.md`의 표를 함께 확인합니다.

예를 들어 다음 수치를 확인할 수 있습니다.

- 연간 총수요량
- 전년 대비 변화율
- 계절별 평균 일일수요량
- 전일 대비 변화율
- 코로나 구간별 평균과 표준편차

### 16.4 Fact와 Hypothesis를 구분한다

데이터에서 직접 확인한 것은 Fact입니다.

예:

```text
2015년 연간 총수요량은 520,746.46 GWh이고, 2025년은 565,048.56 GWh이다.
```

가능한 원인 해석은 Hypothesis입니다.

예:

```text
겨울과 여름의 높은 수요는 냉난방 사용과 관련되었을 가능성이 있다.
```

이 둘을 구분해야 분석 결과를 과장하지 않을 수 있습니다.

## 17. 질문별 최종 결과 요약

자세한 내용은 `REPORT.md`에 정리되어 있습니다. 아래는 핵심 결과만 요약한 것입니다.

### 질문 1. 장기 추세는 어떻게 변화했는가?

2015년부터 2025년까지 전국 전력수요량은 전체적으로 증가했습니다. 연간 총수요량은 2015년 520,746.46 GWh에서 2025년 565,048.56 GWh로 약 8.51% 증가했습니다.

하지만 매년 일정하게 증가한 것은 아닙니다. 2019년과 2020년에는 감소했고, 2021년과 2022년에는 다시 증가했습니다. 2022년에는 574,426.06 GWh로 분석 기간 중 가장 높은 값을 기록했습니다.

따라서 장기적으로는 전력수요 수준이 높아졌지만, 단순한 직선형 증가가 아니라 감소와 회복, 정체가 함께 나타난 흐름으로 볼 수 있습니다.

### 질문 2. 반복되는 계절적 패턴이 나타나는가?

전력수요량에는 반복되는 계절적 패턴이 나타났습니다.

계절별 평균 일일수요량은 다음 순서였습니다.

```text
겨울 > 여름 > 가을 > 봄
```

겨울과 여름은 전력수요량이 높고, 봄과 가을은 상대적으로 낮았습니다. 월별로는 1월과 8월의 평균 일일수요량이 높았고, 5월과 10월은 낮았습니다.

다만 기온 데이터와 용도별 전력사용량이 없기 때문에 이를 냉난방 수요 때문이라고 단정할 수는 없습니다.

### 질문 3. 급격하게 증가하거나 감소한 시점은 언제인가?

전일 대비 변화율을 기준으로 급격한 변화 후보를 확인했습니다.

상위 1% 기준은 20.690%, 하위 1% 기준은 -13.240%였습니다. 이 기준에 해당하는 후보는 증가 41일, 감소 41일로 총 82일이었습니다.

가장 큰 증가는 2024-04-15로 전일 대비 24.324% 증가했습니다. 가장 큰 감소는 2019-09-12로 전일 대비 -22.113% 감소했습니다.

하지만 이 날짜들을 바로 이상치나 특정 원인의 결과로 확정할 수는 없습니다. 공휴일, 명절, 날씨, 산업활동 자료를 추가로 결합해야 원인을 검증할 수 있습니다.

### 질문 4. 코로나 이전·영향 기간·이후는 어떻게 달라졌는가?

평균 일일수요량은 다음과 같았습니다.

```text
코로나 이전: 1,491.14 GWh/일
코로나 영향 기간: 1,498.11 GWh/일
코로나 이후: 1,555.99 GWh/일
```

코로나 영향 기간은 이전보다 약 0.47% 높았고, 코로나 이후 구간은 이전보다 약 4.35% 높았습니다. 표준편차도 코로나 이전 156.99 GWh에서 코로나 이후 183.00 GWh로 증가했습니다.

하지만 이 결과는 코로나가 전력수요 변화를 직접 일으켰다는 의미가 아닙니다. 기온, 산업활동, 경제 상황, 장기 추세 등이 함께 영향을 주었을 수 있습니다.

## 20. AI 활용 방식

이 프로젝트에서는 AI를 다음 작업에 활용했습니다.

- 원본 CSV 구조 파악 보조
- 전처리 코드 작성 보조
- 일별·월별·연별 집계 코드 작성 보조
- 분석 질문별 통계량 계산 코드 작성 보조
- 그래프 코드 작성 보조
- 시계열 분해와 baseline 예측 코드 작성 보조
- Streamlit 대시보드 코드 작성 보조
- 보고서 초안 작성 및 문장 정리 보조
- 영상 자막 구성 보조

미션 요구사항에 따라 AI 활용 내용은 별도 문서인 `AI_USAGE_LOG.md`뿐 아니라 `REPORT.md`의 `AI 활용 및 검증` 섹션에도 함께 정리했습니다.

AI 사용 내역은 다음 세 가지 기준으로 정리했습니다.

1. 사용 작업: 전처리, 시각화, 분석 코드 작성, 문장 정리 등
2. 사용 이유: 시간 절감, 대안 탐색, 코드 구조화, 검증 관점 확보 등
3. 검증 방법: 결과 CSV 대조, 그래프 확인, 수치 재계산, 직접 실행 등

AI가 만든 결과를 그대로 제출하지 않고 다음 방식으로 검증했습니다.

- 실제 CSV의 날짜 범위와 행 수 확인
- 결측 날짜와 중복 날짜 확인
- 일별 합계, 월별 합계, 연별 합계가 서로 일치하는지 확인
- 결과 CSV와 그래프 수치가 일치하는지 확인
- 보고서의 수치가 결과표와 일치하는지 확인
- 원인 설명은 Fact가 아니라 Hypothesis로 분리
- 대시보드를 직접 실행해 메뉴와 그래프 표시 확인

## 21. 검증 방법

이 프로젝트에서는 다음 검증을 수행했습니다.

### 21.1 데이터 검증

- 2015-01-01부터 2025-12-31까지 날짜가 연속적으로 존재하는지 확인했습니다.
- 최종 일별 데이터가 4,018일인지 확인했습니다.
- 결측 날짜가 0일인지 확인했습니다.
- 중복 날짜가 0일인지 확인했습니다.
- 월별 합계와 연별 합계가 일별 데이터에서 다시 계산한 값과 일치하는지 확인했습니다.

### 21.2 분석 결과 검증

- 연도별 총수요량과 전년 대비 변화율을 다시 확인했습니다.
- 월별 평균 일일수요량과 계절별 평균 일일수요량을 확인했습니다.
- 변화율 상위·하위 후보 날짜를 결과 CSV와 대조했습니다.
- 코로나 구간별 평균, 표준편차, 일수를 확인했습니다.
- 보고서의 수치와 결과표의 수치가 일치하는지 확인했습니다.

### 21.3 시각화 검증

생성된 그래프를 직접 열어 다음을 확인했습니다.

- 한글 제목이 깨지지 않는지
- 축 이름이 표시되는지
- 단위가 GWh로 표시되는지
- 범례가 필요한 곳에 표시되는지
- 그래프가 보고서 내용과 일치하는지

### 21.4 대시보드 검증

Streamlit 대시보드를 실행한 뒤 다음을 확인했습니다.

- 모든 메뉴가 정상적으로 이동되는지
- 기간 필터가 동작하는지
- 그래프와 표가 정상적으로 표시되는지
- 급격한 변화 후보 조건 변경이 동작하는지
- 보너스 분석 화면이 정상적으로 표시되는지
- 시연 영상에 필요한 화면 흐름이 자연스러운지

## 23. 한계점

이 프로젝트는 다음 한계를 가집니다.

1. 기온, 습도, 산업생산, 경제성장률, 인구, 전기요금 등 외부 변수를 포함하지 않았습니다.
2. 공휴일과 명절 정보를 결합하지 않았기 때문에 급격한 변화의 원인을 확정할 수 없습니다.

## 25. 자주 발생할 수 있는 문제

### 문제 1. `ModuleNotFoundError`가 발생하는 경우

필요한 라이브러리가 설치되지 않은 상태입니다.

해결 방법:

```powershell
pip install -r requirements.txt
```

### 문제 2. 가상환경 실행이 안 되는 경우

PowerShell 실행 정책 문제일 수 있습니다.

해결 방법:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

그 후 다시 실행합니다.

```powershell
.\.venv\Scripts\Activate.ps1
```

### 문제 3. CSV 파일을 찾을 수 없다는 오류가 나는 경우

`data/processed/` 폴더에 필요한 CSV 파일이 있는지 확인해야 합니다.

필요한 파일은 다음 3개입니다.

```text
daily_demand.csv
monthly_demand.csv
yearly_demand.csv
```

### 문제 4. 한글이 그래프에서 깨지는 경우

실행 환경에 한글 폰트가 없거나 matplotlib 설정 문제일 수 있습니다.

이 경우 코드에서 사용하는 한글 폰트 설정을 확인해야 합니다.

### 문제 5. Streamlit 대시보드가 실행되지 않는 경우

Streamlit이 설치되어 있는지 확인합니다.

```powershell
pip install streamlit
```

또는 전체 라이브러리를 다시 설치합니다.

```powershell
pip install -r requirements.txt
```

## 27. 최종 결론

이 프로젝트에서는 2015~2025년 전국 전력수요량 데이터를 사용해 장기 추세, 계절성, 급격한 변화, 코로나 구간 차이를 분석했습니다.

분석 결과 전력수요량은 장기적으로 증가했지만 매년 일정하게 증가하지는 않았습니다. 겨울과 여름에 높고 봄과 가을에 낮은 계절 패턴이 확인되었고, 일부 날짜에서는 전일 대비 20% 안팎의 큰 변화가 나타났습니다. 코로나 이전·영향 기간·이후 구간의 평균 일일수요량과 변동성에도 차이가 있었습니다.

다만 이 분석은 전력수요량 데이터 자체에서 확인할 수 있는 패턴을 정리한 것입니다. 각 변화의 원인을 설명하려면 기온, 공휴일, 산업활동, 용도별 전력사용량과 같은 외부 데이터를 추가해야 합니다.

따라서 이 프로젝트의 결과는 최종적인 원인 결론이 아니라, 추가 분석을 위한 근거와 가설로 해석하는 것이 적절합니다.
